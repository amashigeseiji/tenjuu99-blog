# 開発サーバー

ソースファイルの変更を検知して再ビルドし、ブラウザで確認できる開発支援環境。

## サーバーの起動（`npx server` / `npm run server`）

`.cache/` へのソースとパッケージの集約 → テンプレートの事前読み込み → 全ページのインデックス化 → 静的サイト生成 → HTTP サーバー起動（ポートは環境変数 `PORT`、既定 8000）。このコマンド自体はファイル監視をしない。

## ファイル監視と再起動（`npx dev-server` / `npm run dev`）

ウォッチャーが `src/`（`src/image/` を除く）・ライブラリ・コアパッケージの変更・追加・削除を監視し、変更のたびにサーバープロセスを終了して起動し直す（全体を再生成する）。ページ単位の差分再生成やブラウザ側の自動リロードは無い。`src/pages/` も監視対象なので、エディタで記事を保存するとサーバーが再起動する。

## 静的配信のルーティング

1. 末尾 `/` → `index.html` を補う
2. `.` を含まないパスは、まずサーバーハンドラー（[サーバー](server.md)）を試し、応答が無ければ `.html` を補う
3. `dist/` に無ければ `src/` を探す
4. 見つからなければ `dist/404.html` を 404 で返す
5. 読み込みで例外が起きれば `dist/500.html` を 500 で返す

Content-Type は拡張子から判定する（`; charset=utf-8` 付き）。
